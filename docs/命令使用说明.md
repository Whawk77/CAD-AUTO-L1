# ASD 插件命令使用说明

整理日期：2026年11月05日。本文按当前源码及 v154 的 ASD2 热重载入口整理。命令在 AutoCAD 命令行输入，不区分大小写；实际交互以命令行提示为准。

## 一、加载与更新

1. 在 AutoCAD 中加载热重载宿主 `LoopHost.dll`。本次支持 ASD2 的宿主位于 `D:\work\AI\claude\ASD-hot-reload\LoopHost\bin\ASD2\LoopHost.dll`，可使用 AutoCAD 的 `NETLOAD` 命令加载。
2. 输入 `ASDHOT`，加载当前构建并显示版本号和构建标识。也可以直接输入已注册的 ASD 命令，宿主会检查并加载当前版本。
3. 业务插件编译出新版后，一般可以在当前 CAD 会话中通过 `ASDHOT` 或 ASD 命令加载；**如果新增了宿主命令注册**，需要重启 CAD 并加载更新后的宿主。

提示：`ASDHOT` 的版本提示说明业务插件已加载，不能单独证明当前宿主已经注册了新增命令。原来的 `Load-ASDHot` 脚本指向 `LoopHost\bin\Debug`，不要把它和上述 `bin\ASD2` 的新版宿主混淆。

## 二、命令速查

| 命令 | 作用 | 是否先清除旧标注 |
| --- | --- | --- |
| `ASD` / `AUTOFIXDIM` | 完整单零件标注 | 否 |
| `ASD2` | 执行 ASD 中除外轮廓尺寸以外的标注 | 否 |
| `ASD3` | 清除最近生成的一个插件标注组 | 是，执行的就是清除 |
| `ASD3V` | 三视图试做：2 或 3 个视图的线性尺寸 | 否 |
| `ASD4` | 清除插件尺寸和核心调试标注，再生成方向诊断 | 是，范围见下文 |
| `ASD5` | 外轮廓相关尺寸 | 否 |
| `ASD6` | 孔、销、槽相关尺寸及引线 | 否 |
| `ASD7` | 倒角、圆角引线 | 否 |
| `ASD8` | 孔径等孔标注引线 | 否 |
| `TY` / `TY1` / `TY2` | 托压块加工标记、引线及相应粗糙度标注 | 否 |
| `AG1` | 对所选直线或多段线直线段生成加工标记及引线 | 否 |
| `ASDREPRO` | 按指定范围清除并生成诊断标注 | 是，范围同 ASD4 |
| `ASDCOREDBG` | 核心规划结果的调试标注 | 否 |
| `ASDCASE` | 保存当前图纸上最近一次成功运行的标注案例 | 不清除；会写案例文件 |
| `ASDHOT` | 加载并显示当前热重载业务版本 | 否 |

## 三、ASD 完整标注

1. 输入 `ASD`。`AUTOFIXDIM` 是相同的主流程入口。
2. 点选或框选**一个零件**的外轮廓及所需几何。轮廓通常选 `DRAWING` 或 `0` 图层的闭合轮廓线；框选中的内部线可能属于同一个零件。选择托压块时，把 TY 生成的标记也框进去。
3. 程序识别轮廓、孔和槽。若未自动识别到孔，可能提示手选圆孔；不需要时按提示跳过。
4. 有销孔或基准需要确认时，按提示选择基准孔、X/Y 基准点、公差和孔组布局。只有一个基准候选时可能自动选择。
5. 按提示放置或跳过孔、倒角、圆角和槽半径引线。引线位置需要交互时，移动鼠标并点击；按命令行提示可跳过或取消。
6. 检查尺寸与引线。ASD 不会预先删除旧结果，重复执行可能叠加标注。

识别不能验证闭合外轮廓时可能使用线弧包围盒作为后备；遇到轮廓异常时应人工核对结果。圆孔、引线是否出现取决于识别结果和交互选择。

## 四、按范围标注

### ASD2：不标外轮廓尺寸

输入 `ASD2`，仍按提示选择零件、孔及基准。它保留孔、销、槽定位尺寸、孔标注以及倒角、圆角、槽半径引线，过滤掉外轮廓尺寸。适合外轮廓已有尺寸、只需补充其他标注的情况。它不预先清除旧标注。

### ASD5：外轮廓尺寸

输入 `ASD5`，选择零件外轮廓。用于生成整体及结构等外轮廓相关尺寸，不执行完整孔及角部标注流程。

### ASD6：孔、销、槽

输入 `ASD6`，选择零件和孔、槽；按需选基准、放置孔标注及槽半径引线。不会绘制外轮廓尺寸或倒角、圆角引线。

### ASD7：倒角和圆角

输入 `ASD7`，选择零件，按提示逐项放置或跳过倒角、圆角引线。它不生成线性尺寸。

### ASD8：孔标注引线

输入 `ASD8`，选择零件及圆孔，按提示放置孔径等孔标注引线；不生成线性尺寸。未找到孔时可以按提示手选。

## 五、清除命令

### ASD3：清除最近一组

输入 `ASD3`，无需框选。程序在当前图纸的模型及布局空间中，按插件记录的组时间寻找最近一组插件标记实体并清除。

**最近一组不一定是 ASD 尺寸**：也可能是刚生成的 `TY`、`TY1`、`TY2`、`AG1` 或 `ASD3V` 输出。若没有可用的组号，可能清除 0 个。

### ASD4：清除后诊断

输入 `ASD4`，按提示选择 `All`、`Top`、`Bottom`、`Left` 或 `Right` 方向，再选择零件并完成后续提示。生成诊断前，它会清除当前图纸**各模型及布局空间**中插件标记为 `Dimension` 和 `CoreDebug` 的实体，并生成诊断结果。它不执行普通 ASD 的后续交互式孔引线流程。

当前版本 TY 的 `SupportBlock` 标记和 AG1 的 `Ag1` 标记不属于 ASD4 的清除类型。**旧版 TY 输出可能标记为 `Dimension`，因此可能被清除。**

`ASD3` 和 `ASD4` 不深入块定义或外部参照；没有插件标记的人工标注不在这两种清除范围内。清除前请确认图纸中的其他插件标注是否需要保留。

## 六、托压块：TY、TY1、TY2

1. 输入 `TY`、`TY1` 或 `TY2`。
2. 选择 `DRAWING` 或 `0` 图层中的一条独立直线 `LINE` 或圆弧 `ARC`；多段线不能直接作为该命令的源对象。
3. 输入方向：`A` 左、`W` 上、`D` 右、`S` 下。偏移量以图形单位计。
4. 按提示选择粗糙度块（如该命令需要）。程序创建虚线和对应引线。

| 命令 | 虚线 | 文字 | 粗糙度 |
| --- | --- | --- | --- |
| `TY` | 洋红色，两条，偏移 1 和 2 | `CNC加工`、`淬火` | 插入选定的粗糙度块 |
| `TY1` | 红色，一条，偏移 1 | `NC` | 插入对应粗糙度块 |
| `TY2` | 红色，一条，偏移 1 | 刻字及两条磨损线说明 | 不插入 |

虚线使用 `DASHED` 线型。如果线型无法加载、找不到虚线可见段，命令会提示并取消。所需粗糙度块缺失时，程序可能保留其他标注并跳过插块。

之后运行 ASD 时，框选包含当前版本 TY 标记的单个零件，可启用托压块规则：保留整体及结构尺寸，减少斜边、倒角和碎段产生的无效尺寸，孔照常处理。ASD 也会尝试调整与新尺寸重叠的 TY 引线文字和粗糙度；请检查 CAD 中实际效果。旧版 TY 标记可能无法触发托压块识别，需要用当前版本重新生成。

## 七、ASD3V：三视图试做

输入 `ASD3V`，一次框选同一零件的 **2 或 3 个分开的视图**。各视图应具有闭合多段线或首尾相接的 `DRAWING` / `0` 图层轮廓线。按提示处理孔和基准；程序会识别各视图、生成线性尺寸，并尝试按投影关系去重。

这是试做功能。它不生成孔径、倒角和圆角引线；需要这些内容时可使用单视图命令。运行后应检查视图分配及命令行中的待确认提示。

## 八、AG1：加工线及引线

输入 `AG1`，按提示选择一条 `LINE` 或二维、三维多段线的直线段。程序根据所选位置和线段方向生成洋红色偏移线，以及 `CNC加工`、`淬火` 引线。图纸已有 `CadAider_国标粗糙度16下` 块时会插入该块；没有时跳过插块，即使命令完成提示提到粗糙度，也应检查图中是否实际出现。AG1 不预先清除旧对象。

## 九、诊断与案例命令

- `ASDREPRO`：先选择 `All`、`Outline`、`Hole` 或 `Corner` 范围，再执行清除和诊断。清除范围同 ASD4，不限于所选零件。
- `ASDCOREDBG`：生成核心规划调试标注，用于排查规划结果；按提示选择轮廓、孔和基准。
- `ASDCASE`：在当前图纸成功运行并生成可保存的标注案例后执行，把结果保存到 `annotation-cases.json`。热重载方式下使用热重载目录配置的案例文件。该命令会写入案例数据，供后续规划使用。

诊断报告通常写入项目的 `diagnostics\last-run.json`，轮廓示意写入 `diagnostics\last-run.outline.svg`；新运行可能覆盖上一次报告。排查时请先保存需要保留的报告。截图用于确认实际布局，JSON 记录识别、规划及部分布局信息，不能代替 CAD 实际检查。

## 十、常见使用方式

- **整件首次标注**：`ASD` → 选零件、孔和基准 → 放置引线 → 检查。
- **外轮廓已标，只补孔和引线**：`ASD2` → 按提示选择零件和孔 → 放置引线。
- **只补外轮廓**：`ASD5` → 选择零件。
- **托压块**：先用 `TY` / `TY1` / `TY2`，再运行 `ASD` 并把 TY 标记框入。
- **撤掉最新插件组**：确认最新组的内容后运行 `ASD3`。
- **排查异常**：先保留图纸和已有报告，再视需要使用 `ASD4` 或 `ASDREPRO`；注意这两个命令的清除范围覆盖当前图纸的各布局空间。
