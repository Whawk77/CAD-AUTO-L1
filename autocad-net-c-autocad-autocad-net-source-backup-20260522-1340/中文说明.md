# AUTOFIXDIM / ASD 文档中文说明

整理日期：2026-05-26

## 这份说明的用途

本文件用于解释同目录下两份核心交接文档的作用：

- `AGENTS.md`：给后续 AI / Codex 看的项目规则手册。
- `PROJECT_HANDOFF.md`：给接手开发者看的项目交接说明。

如果只是想快速了解当前插件状态，先读 `PROJECT_HANDOFF.md`；如果要继续让 AI 修改代码，必须让它遵守 `AGENTS.md`。

## `AGENTS.md` 说明

`AGENTS.md` 不是开发日志，而是“下次改代码必须遵守的规则”。它记录的是容易踩坑、不能遗忘、会影响代码正确性的约束。

重点内容包括：

- 安全规则：禁止批量删除文件或目录。
- 环境信息：当前 L1 工作区、源码目录、AutoCAD 2020 路径、编译命令、部署脚本和 DLL 输出位置。
- 产品边界：主命令是 `ASD`，兼容旧命令，不创建 `CENTER` 图层，不生成中心线。
- 识别规则：外轮廓、倒角、圆角、孔、销孔、螺纹孔、U 槽的识别逻辑。
- 标注规则：总尺寸优先、孔位尺寸优先按销孔基准传递、普通孔和螺纹孔不参与销孔组传递。
- 样式规则：线性标注、直径标注、角特征引线、文字颜色和图层的使用方式。

2026-05-26 补充的关键规则：

- 竖向内凹槽倒角识别必须确认内部竖线另一端连接到另一个倒角、45 度线段或圆角，避免把长斜边误识别成倒角。
- 角特征引线跟随当前图层和当前 `CECOLOR`，角特征文字保留在标注图层，并使用直径/角特征标注样式的文字颜色。
- 孔位尺寸按几何位置进入对应侧的延迟队列：下方孔走 Bottom，上方孔走 Top，左侧孔走 Left，右侧孔走 Right。
- 如果销孔组基准孔在上下或左右之间居中，则选择基准边相反侧，避免和基准侧尺寸挤在一起。

## `PROJECT_HANDOFF.md` 说明

`PROJECT_HANDOFF.md` 是项目交接文档，面向接手开发者。它比 `AGENTS.md` 更像“项目地图”，用于快速理解插件现在能做什么、源码结构在哪、当前逻辑状态如何验证。

重点内容包括：

- 项目目标：AutoCAD 2020 .NET Framework 插件，用于半自动夹具零件标注。
- 当前工作流：选择外轮廓、选择基准、识别孔和特征、生成线性尺寸、交互放置倒角/圆角/直径标注。
- 源码分工：`Commands.cs`、`GeometryCollector.cs`、`FeatureRecognizer.cs`、`DimensionDrawer.cs` 等文件各自负责什么。
- 关键规则：孔识别、外轮廓总尺寸、倒角/圆角、尺寸抑制、台阶/凸台、孔位、直径和粗糙度标注。
- 当前代码状态：当前有效入口和主要方法名。
- 已知问题：台阶尺寸仍处于 AutoCAD 视觉测试阶段，粗糙度块位置可能还需要进一步精确。
- 验证清单：编译命令、NETLOAD 加载 DLL、运行 `ASD` 后需要人工确认的图面效果。

2026-05-26 补充的关键内容：

- 新增 `Recent Source Changes`，集中说明最近源码改动。
- 补充孔位尺寸自动分侧逻辑：销孔组、普通孔、螺纹孔都会根据目标孔靠近的外轮廓侧决定标注放在哪边。
- 补充内凹槽倒角识别限制：必须是“倒角/45 度段 + 内部竖线 + 倒角/圆角”这类真实结构，不能把单独斜边当倒角。
- 补充角特征引线样式规则：引线跟当前图层和颜色，文字跟标注样式文字颜色。
- 在人工测试清单中加入对应验证项，方便 AutoCAD 里逐项确认。

## 推荐阅读顺序

1. 想了解项目现状：读 `PROJECT_HANDOFF.md`。
2. 想继续修改代码：先读 `AGENTS.md`，再读 `PROJECT_HANDOFF.md`。
3. 想确认最近补了什么：读 `PROJECT_HANDOFF.md` 的 `Recent Source Changes`。
4. 想做 AutoCAD 人工验证：读 `PROJECT_HANDOFF.md` 的 `Manual AutoCAD Test Checklist`。

## 后续维护原则

- 新增功能或行为变化，应优先更新 `PROJECT_HANDOFF.md`。
- 只有“下次 AI 改代码不看就会犯错”的规则，才写进 `AGENTS.md`。
- 不要把单次开发流水账塞进 `AGENTS.md`。
- 不要用“今天、昨天、最近”这类相对时间，统一写绝对日期。
