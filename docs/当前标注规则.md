# 当前标注规则

整理日期：2026-10-30（与源码对齐：命令列表、图层/样式、FeatureFirst 开关、托压块与三视图）

本文总结当前工作树中 AutoCAD 自动标注的主要识别、规划、布局、渲染和清理规则。详细实现以源码及以下专项文档为准：

- [RecognitionRules.md](RecognitionRules.md)
- [DimensionRules.md](DimensionRules.md)
- [不遮挡中心线标注规则.md](不遮挡中心线标注规则.md)
- [DimensionLayoutRegression.md](DimensionLayoutRegression.md)
- [RotationInvariance.md](RotationInvariance.md)

## 1. 识别范围

- 只处理用户当前选择或框选的对象，不扫描整个模型空间。
- 外轮廓主要识别 `DRAWING` 和 `0` 图层；实体线型按图层语义判断，中心线、隐藏线、虚线和构造线不作为普通外轮廓。
- 主外轮廓优先取闭合或连续的真实几何；没有闭合多段线时，回退到最佳连续线/圆弧/多段线组件。
- 外轮廓包络必须来自真实 `MainOutline`，并包含直线、圆弧、圆角、倒角和多段线凸度。
- 识别对象包括普通孔、销孔、螺纹孔、U 型槽、倒角和圆角。
- 螺纹小径圆只用于推断螺纹标注，不再重复生成普通直径标注。

## 2. 尺寸对象与夹点

- 先确定真实特征关系，再确定尺寸夹点。
- 尺寸只能附着到真实边、圆弧、端点或真实交点。
- 禁止附着理论交点、虚拟尖角、倒角切点、投影点、尺寸线或浮动点。
- 已被选中的 `CENTER` 中心线端点，只允许用于孔/槽定位尺寸；不得创建新的中心线或 `CENTER` 图层。
- 零长度尺寸不得生成。

## 3. 总体与结构尺寸

- 总宽、总高优先，取真实外轮廓的完整包络。
- 不得用局部台阶、倒角切线、圆角切线或特征投影尺寸替代总体尺寸。
- 与总体尺寸仅构成重新分段关系的局部 `OutlineSegment` 尺寸成对抑制。
- Top、Bottom、Left、Right 使用各自的结构尺寸链；同侧结构段使用统一的根对齐关系。
- 外轮廓轴线上的局部结构尺寸可被抑制，但总体、孔、销孔、槽、基准和功能孔尺寸受保护。
- 四向旋转时，结构尺寸的真实跨度集合应保持一致；放置侧可以变化，但不能用残差跨度或肩高替代真实槽宽/台阶净宽。
- `ASD` 系列（`ASD`、`AUTOFIXDIM`、`ASD4`–`ASD8`、`ASDREPRO`，经 `RunAutoFixDim`）、`ASD3V`、`TY`/`TY1`/`TY2` 均将 `UseFeatureFirstStructurePipeline` 设为 `true`；`CreateDefault()` 中的默认字段仍为 `false`。`ASDCOREDBG` 与 `AG1` 直接使用 `CreateDefault()`，未开启该开关。`TY` 系列不经过 `DimensionPlanner`，该设置对其无实际作用。

## 4. 孔、销孔与定位链

有销孔时采用销孔优先逻辑：

- **A：** 基准边到首个销孔。
- **C：** 同组基准销孔到其他销孔。
- **B：** 首组基准销孔到后续销组。

方向规则：

- 水平 C：销孔靠近 `Ymin` 时放 Bottom，否则放 Top；相等时取 Bottom。
- 竖直 C：销孔靠近 `Xmin` 时放 Left，否则放 Right；相等时取 Left。
- B 在对应销组的 C 侧生成，并与 C 共用尺寸线。
- A 只有在与 C 同侧时才加入同一根尺寸链；不同侧时保持独立对齐键。
- 每个后续销组独立判断自己的 C 侧，不借用其他销组的配对键。
- 普通孔和螺纹孔不建立销组基准；没有销孔时才退回外轮廓/基准边定位。
- 归属于销组的功能孔从该组基准销孔定位；其余孔作为松散孔链处理。
- 松散孔链可使用附近有效局部边界，但尺寸线必须位于真实轮廓外，不得仅为避让而移到远端全局侧。

## 5. 孔阵列、槽与中心线端点

- 水平孔距优先连接同行相邻孔，竖直孔距优先连接同列相邻孔。
- 不得按全体孔心全局排序生成对角孔距。
- Bottom/Top 使用特征竖直中心线的下/上端点。
- Left/Right 使用特征水平中心线的左/右端点。
- 双圆弧槽必须先选择朝向布局侧的外侧圆弧，再选择对应中心线端点。
- 槽定位尺寸及其关联中心距尺寸必须保持同侧、同链和同一对齐关系。
- `isAttachmentValid=true` 只能说明夹点落在真实中心线端点上，仍需额外确认孔对、槽段和布局语义正确。

## 6. 容差与标注文字

默认规则配置集中在 `CadAuto.Core/Rules/DimensionRuleConfig.cs`：

| 项目 | 当前值 |
| --- | --- |
| 销孔配合 | `H7` |
| 同组销孔中心距 | `±0.02` |
| 销组间距 | `±0.05` |
| 基准孔 X/Y 定位 | 默认无容差；输入 `S` 时为 `±0.05` |
| 螺纹小径匹配容差 | `0.25` |

- 直径文字使用 AutoCAD 控制码 `%%c`，不使用 Unicode 直径符号。
- 螺纹小径按当前映射生成 `M6`、`M8`、`M10`、`M12`、`M16` 等文字。
- 倒角整数显示为 `C5` 等形式，不追加无意义的小数；非整数使用当前角部/直径样式精度。
- 倒角使用 `Leader + MText`，圆角使用 `RadialDimension`，孔/螺纹使用 `DiametricDimension`。

## 7. 尺寸排列与避让

- 同侧阅读层级为：局部孔距 → 组内销距 → 基准/组间距 → 总体尺寸。
- 同一层级内通常短尺寸靠内、长尺寸向外。
- A、C、B 定位链尽量保持连续；文字、箭头或轮廓冲突时整体外移。
- 局部边界无效时回退到 `MainOutline` 全局边界。
- 必须检查文字框、箭头、延伸线和外轮廓覆盖，不能只检查夹点是否合法。
- 共享延伸线可用于对齐，但不能移动真实箭头端点已经与其他尺寸重合的尺寸。

## 8. 图层、样式与生成对象

- 当前源码实际将生成实体写入当前图层；`JEE-DIM标注` 常量仍保留，但当前图层解析器未强制切换到该层。
- 线性尺寸使用当前数据库尺寸样式 `db.Dimstyle`；代码中不存在 `SCALE-1-*` 样式查找。
- 直径/螺纹标注优先使用“当前尺寸样式名 + `$3`”子样式，找不到时回退到当前样式。
- 生成的尺寸、引线、粗糙度块和调试对象必须带有 `AUTOFIXDIM` XData。
- 清理操作只删除带有 `AUTOFIXDIM` 且属于允许类型的插件对象，不删除用户手工标注。
- 基准孔 X/Y 只有在对应方向启用容差时才插入粗糙度块。

## 9. 诊断与验收口径

- `ASD4` 用于按 All、Top、Bottom、Left、Right 方向生成诊断结果。
- 诊断报告中的候选、选中和抑制状态用于定位规则裁决；调试标签重叠不等同于产品尺寸渲染失败。
- L 型结构覆盖规则只处理符合 `StepRiser:` 来源条件的候选；`NoClosedTopologyProof` 不能单独证明真实几何开口。
- 四向回归必须分别运行并归档各方向的诊断报告，再做结构化校验和图像复核。
- 报告、静态测试和结构化校验不能替代 AutoCAD 中对文字、箭头、延伸线和实际附着效果的实时验收。

## 10. 当前边界

本文是规则摘要，不改变现有代码行为。当前文档整理未执行编译、AutoCAD 启动或四方向回归；最终 DLL 的实时效果仍需按项目部署和回归流程单独验证。

## 11. 托压块命令（TY / TY1 / TY2）

实现位于 `SupportBlockCommand.cs`，不经过 `DimensionPlanner`，不使用外轮廓识别、销孔链或抑制流水线。

输入与方向：

- 通过 `GetEntity` 逐个选择单条 `LINE` 或 `ARC`；图层必须为 `DRAWING` 或 `0`，长度不得小于 `GeometryTolerance`，否则提示重选。
- 复制方向由关键字选择：左 `A`、上 `W`、右 `D`、下 `S`。偏移单位为 1 个图形单位的整数倍。
- 选择源为 `Line` 时按起止点复制；为 `Arc` 时克隆并平移，保留线型比例、线宽和透明度。

生成对象：

| 命令 | 复制份数（偏移） | 复制线颜色 | 引线文字 | 粗糙度块 |
| --- | --- | --- | --- | --- |
| `TY` | 2（1、2） | ACI 6（洋红） | `CNC加工`、`淬火` | 插入（先提示选择粗糙度块） |
| `TY1` | 1（1） | ACI 1（红） | `NC` | 插入（`ty1` 变体） |
| `TY2` | 1（1） | ACI 1（红） | `刻+字两条磨损线` + 换行 + `（V型深度0.2 宽度0.5）` | 不插入 |

- 复制线线型固定为 `DASHED`；当前图纸不存在时依次从 `acadiso.lin`/`acad.lin`（按 `MEASUREMENT` 决定先后）加载，加载失败则取消命令。
- 复制线写入当前图层（`database.Clayer`），不使用 `DRAWING` 图层。
- 引线箭头位置取复制线 DASHED 图案中“可见实线段”的中点：按线型图案长度 × 对象线型比例 × 全局 `LTSCALE` 展开；找不到可见实线段则取消命令。
- 水平线取 X 方向、竖直线取 Y 方向判定可见段的最小或最大端；`CNC加工` 与 `淬火` 取相反端。
- 引线文字和落点按 `DimensionRuleConfig` 的 `FirstDimOffset`、`LeaderOffset`、`DimTextClearance`、`GeometryTolerance` 与直径标注样式字高计算，不做与既有尺寸的碰撞检测。
- 生成对象均带 `AUTOFIXDIM` XData（`KindDimension`），可由 `ASD3` 清除。

## 12. 三视图试做（ASD3V）

实现位于 `ThreeViewTrialCommand.cs`。

- 需要 2 或 3 个相互分开的视图闭合外轮廓，否则提示后结束。
- 每个视图独立识别并生成 `DimensionPlan`，随后由 `OrthographicViewSetAssigner` 分配视图角色，并对跨视图重复的线性尺寸去重；保留待确认的 `CrossView.*` 警告会输出到命令行。
- 只绘制线性尺寸；直径、倒角和圆角引线仍用单视图命令生成。
- 仅在有销孔且该视图被标记为保留销孔尺寸时，才提示选择基准孔与基准点。
