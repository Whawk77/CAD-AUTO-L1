## 修改内容

### 外轮廓选择不再要求点选
- 现象：实图 run 20261103000252033（50×51，底面打进三个孔），ASD 提示"发现多个可能轮廓或未闭合对象，请点选本次需要标注的外轮廓"。
- 原因：选择阶段按端点相连分组。孔壁线下端落在底边中间（T 字连接），单独成组；该组包络贴着底边，不满足"严格在外轮廓内部"，被当成疑似另一个零件。
- 规则（用户确认）：ASD 每次框选单一零件。`OutlineSelectionRules.SelectSinglePartExterior` 取拓扑验证闭合的线组中外包络面积最大的一组作外轮廓，其余线组都是该零件的内部结构；面积相同取先出现的一组。没有闭合线组时返回 -1，`GeometryCollector` 走原有的闭合多段线、线/圆弧兜底规则。
- `GeometryCollector.PromptForOutlineSelection`：去掉点选循环；`FindExteriorCandidates` 及其 `Encloses` 已删除。
- 诊断：`OutlineSelection.SelectionDecisions` 写入报告 `selection.outlineSelectionDecisions`，每个线组一条（`Component`、`Closed`、`EnvelopeArea`、`Decision`、`Handles`），兜底时追加 `Fallback=…`。
