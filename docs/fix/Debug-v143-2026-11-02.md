## 修改内容

### 1. L 型规则去掉方向依赖（A1：在标准朝向里计算）
- `LProfileShapeRules`：判定结果新增 `InnerHorizontalLength` / `InnerVerticalLength`（内凹角两侧内侧臂面补成虚拟尖角后的长度），写入 Evidence（`InnerH=…|InnerV=…`）。
- `DimensionPlanner.CreateDimensionPlan` / `CreateOutlinePlan` 新增参数 `allowLProfileQuarterTurn`：调用方给 WCS 时，若判定为 L 型且较长内侧臂面竖直，改在转 90° 的坐标系里规划（局部 (x, y) = (世界 y, −世界 x)），记 `CoordinateFrame.LProfileQuarterTurn|…`。只对 L 型生效，其他零件、斜放零件不变。
- `Commands.CreatePlanWithStructureDatumSelection`：开启上述参数；左右/上下基准块冲突提示按局部轴换回世界轴。
- `CoordinateFrameModelTransform.ToLocal(Datum2D)`：坐标系为 90° 整数倍时，`StructureDatumMinimumX/Y`、`DatumHoleLocationBaseX/Y`、`DatumHoleLocationUseToleranceX/Y`、销组左右/上下布局偏好按轴换算（原先原样拷贝）。
- `DimensionDrawer`：图上已有尺寸投影到规划坐标系后再判断占用的尺寸层（原先非 WCS 时直接忽略已有尺寸）。

### 2. 槽壁规则
- `StructureBoundaryEvidence.RejectGrooveWithoutBoundaryWalls`：槽每个端位上必须有真实外轮廓侧壁，否则不生成该槽，记 `GrooveWallNotOnBoundary`。
