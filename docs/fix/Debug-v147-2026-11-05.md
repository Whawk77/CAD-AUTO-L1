## 改动

托压块模式（框选里有 TY/TY1/TY2 生成的对象，XData Kind=SupportBlock）：

1. 虚拟轮廓（`SupportBlockRules.BuildOrthogonalOutline`）：规划前把外轮廓整理成只有横竖边的轮廓。同线碎段合并；一串斜边、倒角、圆弧夹在一横一竖之间补成尖角，夹在错开的平行面之间换成立面（贴包络就放包络上，否则取整数坐标，否则取中点），夹在同一条线上就去掉。
2. 新增 T 型分类（`SupportBlockRules.ClassifyT`）：虚拟轮廓 8 个顶点，一侧是通长横梁边，对侧只有一条凸台底边且不碰两端，横梁内侧两段同线。
3. T 型规则（`DimensionPlanner.TryAddSupportBlockTDimensions`），只对 T 型生效，不再跑结构、基准基线和 L 型规则：
   - 沿横梁：总长、凸台宽、从较近的包络端量到凸台远边的定位（远边不是整数而近边是整数时改量近边），三个都放凸台一侧。
   - 垂直横梁：总高放定位起点一侧；横梁厚与凸台高二选一放对侧，优先整数，都是整数取短的。
   - 倒 T 实图结果：50、20、25 在下，31.56 在左，20 在右；不标 5 和 11.56。8 种摆法数值一致。
4. 其他托压块形状（如 L 型）走虚拟轮廓 + 现有规则，再按"优先整数"去掉可推算的尺寸（a+b=总，去掉非整数的；都是整数去掉最大的；总尺寸不去）。
5. PostValidator：`SupportBlock.T.*` 的总尺寸允许放在两侧之一。
6. 孔照常标。普通 ASD（无 TY 对象）不受影响。
