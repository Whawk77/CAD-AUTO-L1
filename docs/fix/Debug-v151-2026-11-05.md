## 问题

倒角标注显示 `2-C0.50`，末尾多一个 0。

## 原因

倒角文字是插件自己拼的字符串（`DimensionDrawer.ApplyChamferTextPrecision`）：按角部/直径标注样式的小数位数（DIMDEC=2）格式化成 `0.50`。线性尺寸由 CAD 按样式的 DIMZIN 自动去掉末尾的 0，但这段字符串是 override 文字，CAD 不会处理。

## 改动

- `ApplyChamferTextPrecision`：角部标注样式或线性标注样式开了"消除后续零"（DIMZIN 含 8）时，去掉末尾的 0 和多余的小数点，例如 `C0.50` → `C0.5`，`C1.25` 不变，整数仍显示为 `C5`。样式没开消零时保持原来的固定位数。
- `docs/当前标注规则.md` 的倒角条目补充这条。

## 验证

- 编译通过。CAD 实测：同一张图的倒角应显示 `2-C0.5`。如果仍是 `C0.50`，说明当前样式的 DIMZIN 没有开消除后续零，需要确认是否不管样式一律去掉末尾的 0。
