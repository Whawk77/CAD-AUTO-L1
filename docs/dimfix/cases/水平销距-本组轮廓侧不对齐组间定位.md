# 水平销距按本组轮廓侧，不同侧的组间定位不对齐

## 症状类别

摆放层

## 诊断证据

运行 `20260923165108095`（Debug-v48）。PG4 水平销距 30（候选 id=30，X 从 -8 到 22）和组间定位 223.5 被放进底边车道 `AlignmentLane:PG1:DatumChain:H#2`，尺寸线 Y=-29.5。该组销在约 Y=191.5，离外轮廓 Ymax 更近。图上延长线从顶排销钉拉到 Top 的对侧。

## 错误代码（文件与分支）

`CadAuto.Core/Planning/DimensionPlanner.Features.cs`

- `AddSameGroupPinDistances`：水平 `PinDistance` 使用 `groups[0].HorizontalSide` 和基准对齐键。
- `AddPinGroupBaseTransfers`：水平 `PinGroupDistance` 一律带 `PG1:DatumChain:H`。
- 生成顺序原先是 A、B、C。

## 确认的标注规则

用户原话：A到C到B，C的布局位置应该考虑自身销孔组离外轮廓ymin和ymax，取ymin方向（这是水平方向的尺寸，考虑尺寸位于top端还是bottom端）；然后在生成B,若A和C布局位置不在一个方向，不需要强行对齐。B要与C对齐。垂直方向的尺寸也要这样。

可执行判断：

- 每一组销孔都单独走这条规则，不限于第二组。
- A 是第一组基准定位。水平侧别仍是第一组 `HorizontalSide`，垂直侧别仍是第一组 `VerticalSide`。
- 先生成 C（同组销距），再生成 B（从第一组基准销量到该组基准销）。
- 水平 C：本组各销到外轮廓 Ymin、Ymax 的最近距离。离 Ymin 更近或两边相等时放 Bottom，否则放 Top。
- 垂直 C：本组各销到外轮廓 Xmin、Xmax 的最近距离。离 Xmin 更近或两边相等时放 Left，否则放 Right。
- B 放在该组 C 的同一侧，并和 C 画在同一条尺寸线上。与 A 同侧时，A、B、C 共用基准对齐键。不同侧时，这一组的 B 和 C 用 `PGn:PinPair:H` 或 `PGn:PinPair:V`，A 留在自己的一侧。别的组不共用这把键。

## 代码改动

`AddHolePositionDimensions` 先生成 C 再生成 B。水平侧别由 `ChoosePinGroupHorizontalLayoutSide` 决定，垂直侧别由 `ChoosePinGroupVerticalLayoutSide` 决定。B 使用该组 C 的侧别。同侧时对齐键是基准链；不同侧时这一组的 B 和 C 用 `GetPinGroupPairAlignmentKey`。循环覆盖每一个后续销孔组。

规则正文见 `docs/DimensionRules.md` 的 Pin And Hole Position Dimensions。

## 下次匹配条件

某一组的水平或垂直销距、组间定位被放进第一组基准车道，而这组销孔离另一侧外轮廓更近。第三组及以后同样匹配。

## 不能套用

功能孔和松散孔。它们不按销距 C 的侧别重放。
