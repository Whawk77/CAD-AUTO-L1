## 修改内容

### 内部线不再生成凸台台阶面尺寸
- 现象：实图 run 20261102234708589，50×57 矩形外轮廓内有 y=37 的内部横线（E7、E14）和 x=15、35 的内部竖线（E11、E9），ASD 标出了 E11–E9 之间的 20 和 E9 到右边的 15。
- 原因：`StructureFeatureExtractor.AddBossLedgesFromSegments` 遍历全部线段找凸台台阶面，不检查是否在外轮廓上，生成的特征也没有要求外轮廓支撑，`StructureBoundaryEvidence.EnforceSelection` 因此放过了它们。
- 修改：拓扑判为 `NonBoundary` 的线段生成的台阶面特征，标记 `RequiresOuterBoundarySupport = true`、`BoundaryMembership = NonBoundary`（证据 `StructureBoundary|Relation=BossLedgeSegment|…`），由 `EnforceSelection` 去掉，原因记 `StructureSourceNotOnExteriorBoundary`。特征仍保留在凸台候选列表里，`RecoverInnerBossGroove` 可以把它改写成经过验证的内凸台槽路径。外轮廓线段、归属未知的线段不变。
