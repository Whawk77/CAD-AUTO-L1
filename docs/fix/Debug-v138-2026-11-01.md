# Debug-v138 (2026-11-01)

## 主要变更

实现了"台阶轮廓改为从基准边量尺寸"的新规则,适用于所有满足条件的台阶轮廓。

## 新规则说明

### 适用范围

满足以下所有条件的轮廓应用基准基线规则:
- 唯一闭合外轮廓
- 边界无圆弧
- 所有斜边都是已识别的倒角
- 至少有一个内部台阶层

### 标注规则

1. **基准选择**:
   - 有有效基准块: 用块确认的边
   - 无基准块: 左下优先 (MinX,MinY) → (MinX,MaxY) → (MaxX,MinY) → (MaxX,MaxY)
   - 无真实角点: 回退到几何最小值 (MinX, MinY)

2. **尺寸内容**:
   - 每个台阶面只标一个尺寸: 到基准边的距离
   - 不标注面自身长度
   - 倒角切掉的面: 远层 = 近层 + C (不单独标)

3. **尺寸放置**:
   - 优先放基准侧
   - 尺寸界线穿过实体时自动切换到对侧

## 核心实现

### 新增文件

- `CadAuto.Core/Rules/DatumBaselineRules.cs` - 计算要标注的台阶层
- `CadAuto.Core/Planning/DimensionPlanner.DatumBaseline.cs` - 生成和替换尺寸

### 修改文件

**规划器**:
- `DimensionPlanner.cs` (256-259 行) - 接入新流程
- `DimensionPlanner.StepDatum.cs` (98-114 行) - 基准角点选择逻辑
- `DimensionPlan.cs` - 新增 `RemoveStructureDimension` 方法

**规则**:
- `StructureDatumRules.cs` - 新增 `HorizontalBaselineRule` 和 `VerticalBaselineRule`
- `BoundaryLineRuns.cs` - 处理分段边的合并

### 关键实现细节

1. **unmeasuredTargets 处理**:
   - 存储无法从基准测量的目标的绝对坐标
   - 用于区分合法的局部补充尺寸和内部线残留

2. **三种残留抑制逻辑**:
   - `OffBoundaryArtifact`: 端点不在外轮廓上
   - `InternalLineArtifact`: 一端已知,另一端既非目标也非已知
   - `OrphanedTargetArtifact`: 两端未知,一端是未测量目标,另一端不是

3. **Source ID 合并**:
   - 基线尺寸替换相同区间的旧尺寸时
   - 合并旧尺寸的 SourceGeometryIds 到基线尺寸
   - 保持对原始几何边的可追溯性

## 已知限制

1. **圆弧轮廓**: 有未识别圆弧的轮廓不适用基线规则,回退到旧规则
2. **复杂倒角**: 多个倒角交汇可能导致某些位置无法从基准测量
3. **动态块**: 未验证的动态块会被拒绝,回退到几何基准
