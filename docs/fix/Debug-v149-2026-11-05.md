## 需求

托压块模式下，ASD 尺寸和 TY/TY1/TY2 生成的引线文字、粗糙度块重叠时，调整 TY 标注避开尺寸（用户 2026-11-05 确认方案）。

## 改动

- 新增 `CadAuto.Core/Rules/SupportBlockCalloutLayout.cs`：输入一组 TY 标注（文字、粗糙度块）的外框和 ASD 尺寸外框。先看这组标注在包络哪一侧，确认和尺寸真的重叠，再算出移到这一侧最外层尺寸外 gap 处的位移。只统计明显伸到这一侧外面的尺寸，另一方向贴边起止的尺寸不算。不重叠返回 null。目标位置是绝对的，重复运行 ASD 不会累加。
- 新增 `CadAuto.CadAdapter/Rendering/SupportBlockCalloutAdjuster.cs`：用框选里 Kind=SupportBlock 对象的 GroupId，到当前空间找全同组的 MText、粗糙度块和 Leader（文字和块可能在框选外）。用 GeometricExtents 求外框，整组平移；Leader 的箭头（第 0 点）不动，其余转折点跟着移动，然后 EvaluateLeader。偏移虚线不动。
- `CadEntityWriter.AppendedIds` 记录本次写入的对象，`DimensionDrawer` 暴露 `AppendedIds` 和 `LinearTextHeight`。
- `Commands.RunAutoFixDim`：托压块模式下线性尺寸画完后调用避让。gap = max(LeaderOffset×DIMSCALE, 2×字高)，和 TY 原来的引线偏移一样。结果写进诊断 warnings（`SupportBlock.CalloutShift|Side=..|Distance=..|Group=..`），命令行提示移动了几组。和 ASD 标注在同一事务里，一次 UNDO 撤回。
- 普通 ASD 不碰 TY 对象。
