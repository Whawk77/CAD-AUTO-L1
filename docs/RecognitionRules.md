# Recognition Rules

## Outline Selection

- Outer contour selection targets real drawing geometry, primarily objects on layer `DRAWING`.
- Entity linetype is treated as `ByLayer`; layer linetype is used to filter center, hidden, dashed, and construction geometry.
- Main outline selection prioritizes layer semantics, lineweight, closed or continuous geometry, and outside bounding extent.
- If no closed polyline exists, fallback should choose the best continuous selected line/arc/polyline component instead of blindly using every selected outline object.
- Overall envelope values must come from the selected `MainOutline`: `MinX -> MaxX` and `MinY -> MaxY`.
- The envelope must include lines, arcs, fillets, chamfers, polyline bulges, and transition edges.

## Hole Recognition

- Hole recognition is based on the current user selection/window selection.
- Normal holes come from selected valid circles inside the outline.
- Pin holes are circles matched to CadAider pin markers.
- Any recognized `HoleKind.Pin` gets `PinHoleFitToleranceText` from `CadAuto.Core/Rules/DimensionRuleConfig.cs`.
- Thread holes are recognized from confirmed thread arcs and minor-circle mapping.
- Thread minor-diameter callouts are configured in `CadAuto.Core/Rules/DimensionRuleConfig.cs`.
- Thread minor circles are used to infer thread callouts and should not also create independent normal diameter callouts.

## Datum Recognition

- Default datum comes from the selected outline envelope.
- If pin holes exist, the user may pick a datum pin.
- The picked datum pin is matched by `ObjectId` first, then by center/radius tolerance fallback.
- Datum-hole X/Y tolerance is controlled by prompt: default no tolerance; `S` adds `DatumHoleLocationToleranceText`.

## Slot Recognition

- U-slot recognition is selected-geometry based.
- A standard U-slot is recognized from two parallel lines plus two half-circle arcs.
- A single-arc slot can be recognized from one half arc plus two connected parallel lines.
- Slot points are represented as `HoleKind.Slot` for positioning logic.
- Slot source entities must be suppressed from normal hole/diameter processing.
- U-slots emit center-distance and datum-side positioning dimensions, but do not emit diameter callouts or slot specification text.
- Same-radius U-slot radius callouts are grouped, for example `2x2-R3.5`.

## Chamfers

- Chamfers are recognized from non-axis 45/135-degree `MainOutline` segments connected to horizontal/vertical outline edges.
- Nearby collinear chamfer extension segments may be merged before calculating the displayed chamfer value.
- Chamfer callout text follows the active diameter/corner callout dimstyle precision for non-integers.
- Integer chamfer values should not show trailing decimals, for example `C5`.
- Inner-groove chamfer recognition supplements missing local 45/135-degree chamfers only for real groove structures.
- Inner-groove detection must not classify a general long inclined structural edge as a chamfer.
- Vertical inner-groove chamfer detection must verify that the internal vertical line's other end connects to another chamfer/45-degree segment or fillet.

## Fillets

- Fillets are recognized from `MainOutline` arcs or polyline bulges with reasonable radius.
- Fillets must be connected to real outline endpoints.
- Fillet/radius leaders attach to real arcs.

## Diagnostics

- `FeatureRecognizer.DiagnosticsEnabled` is disabled in normal source and should only be enabled for targeted recognizer debugging.
- `ASD4` diagnostic labels are generated by `DimensionDrawer`; they are a separate layout/debug mechanism.
